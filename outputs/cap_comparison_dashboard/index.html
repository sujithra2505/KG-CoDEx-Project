How to read this

  • Cap = the most predictions kept for each relation. A bigger cap keeps more, lower-ranked predictions.
  • v1 / v2 = two rankings of the same candidates. v2 breaks ties using how much training evidence supports a prediction.
  • Positive match (TP) = a prediction found in the split's positive triples. Negative match (FP) = a prediction found in the split's supplied negatives.
  • Unlabelled = in neither file. It is not counted as wrong — the benchmark simply cannot judge it.
  • Benchmark precision = TP / (TP + FP), only over labelled predictions. It is not accuracy over all predictions.
  • Recall = TP / all positives of the split. F1 = 2TP / (2TP + FP + FN). Positive hit rate = TP / all predictions (a lower bound).
  • The charts use the validation split. Validation was already used in Phase 4, so its numbers are a little optimistic. The test split is kept for the final check (below).
